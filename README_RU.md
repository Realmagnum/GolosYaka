ГолосЯка превращает речь в чистый текст прямо под курсором (`⌥ + Space`), локально расшифровывает длинные аудио- и видеозаписи без отправки в облако и при желании обрабатывает заметки или выделенный текст через выбранного вами ИИ-провайдера.

## Ключевые возможности

- **100% локальное распознавание речи** — **Sber GigaAM v3** и **Whisper Large v3 Turbo** на Apple Silicon (~70 МБ RAM в фоне). Голос не покидает ваш Mac.
- **Мгновенный ввод под курсор** — диктуйте в любое приложение (Xcode, VS Code, Obsidian, Telegram, Slack, браузеры) по переключателю или в режиме удержания (Push-to-Talk).
- **Словарь IT-терминов и автообучение** — автоматически исправляет англоязычные термины и рунглиш (`Tailscale`, `OpenCode`, `Ollama`, `Kubernetes` и др.) с буфером кандидатов от ИИ.
- **Расшифровка длинных записей без потерь** — делит аудио по адаптивным границам тишины, не обрезая слова на стыках чанков.
- **Караоке-тайминги и сравнение этапов** — подсветка слов при прослушивании и переключение между сырым ASR, словарём терминов и финальной ИИ-редакцией.
- **ИИ-обработка выделенного текста (`⌥ + ⇧ + Space`)** — выделите текст в любом окне для саммари, редактуры, перевода или запуска своего промпта с потоковым ответом.
- **Свобода выбора ИИ (Primary + Failover)** — OpenAI, DeepSeek, Groq, Neuraldeep, Ollama / LM Studio или любой OpenAI-совместимый endpoint с автоматическим переключением на резервный провайдер.

## Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `⌥ + Space` | Старт / стоп диктовки (или запись при удержании в режиме Push-to-Talk) |
| `⌥ + ⇧ + Space` | ИИ-обработка выделенного текста в любом приложении |
| `Esc` | Мгновенная отмена текущей записи без сохранения и вставки |

## Установка

1. Скачайте свежий `GolosYaka.dmg` из раздела [Releases](https://github.com/Realmagnum/GolosYaka/releases).
2. Перетащите `GolosYaka.app` в папку `/Applications`.
3. Снимите карантин macOS перед первым запуском (приложение распространяется с открытой ad-hoc подписью):

```bash
xattr -cr /Applications/GolosYaka.app
```

4. Разрешите доступ к **Микрофону** (запись голоса) и **Универсальному доступу** (вставка под курсор и обработка выделения).

> **При обновлении:** так как ad-hoc подпись меняется от сборки к сборке, после обновления может потребоваться удалить ГолосЯку кнопкой `−` в *Системные настройки → Конфиденциальность и безопасность → Универсальный доступ* и добавить заново.

## Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **ОС** | macOS 13.0+ (Ventura, Sonoma, Sequoia) |
| **Процессор** | Apple Silicon (M1 – M5) |
| **Движки распознавания** | GigaAM v3 RNN-T (`GGUF Q8_0`), Whisper Large v3 Turbo, внешний ASR |
| **Потребление памяти** | ~70 МБ в ожидании / ~100 МБ при распознавании |
| **Языки интерфейса** | Русский и английский (переключение на лету) |

## Сборка из исходников

```bash
git clone https://github.com/Realmagnum/GolosYaka.git
cd GolosYaka

# Скачать веса модели GigaAM v3
curl -L -o GolosYaka/gigaam.gguf \
  https://huggingface.co/memoravox/gigaam-v3-e2e-rnnt-gguf/resolve/main/gigaam-v3-e2e-rnnt-Q8_0.gguf

# Собрать и запустить в Xcode
open GolosYaka.xcodeproj
```
