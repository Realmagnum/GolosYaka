# Голосок: Локальное распознавание речи для macOS

**Нативный голосовой ввод на базе Sber GigaAM v3. Инференс на Apple Silicon.**  
Моментальный ввод текста по `⌥ + Space`, офлайн-расшифровка медиафайлов и опциональная ИИ-обработка через вашего провайдера.

## Что нового в ветке DEV

* **Расшифровка длинных записей без потери слов.** Длинное аудио делится на перекрывающиеся чанки с адаптивными границами по тишине, поэтому фразы на стыках больше не обрезаются.
* **Компенсация IT-терминов.** Встроенный словарь возвращает искажённые английские термины (`Tailscale`, `OpenCode`, `Hindsight`, `Ollama`, `Vaultwarden` и др.). Свои термины можно добавлять, импортировать, экспортировать и редактировать.
* **Автообучение ИИ с буфером проверки.** Новые созвучные варианты попадают в список кандидатов. Каждого кандидата можно отредактировать, одобрить или отклонить, а накопленный список — проверить пакетно через ИИ.
* **ИИ-обработка заметок и выделения.** Саммари, протоколы встреч, улучшение стиля, перевод и пользовательские промпты. Результат приходит потоком, с управлением ризонингом.
* **Горячая клавиша обработки выделения.** Выделите текст в любом приложении и нажмите `⌥ + ⇧ + Space`, чтобы применить ИИ-действие только к фрагменту.
* **Любой OpenAI-совместимый провайдер.** OpenAI, DeepSeek, Groq, Neuraldeep (OAuth), Ollama/LM Studio или собственный endpoint. У каждого провайдера свои Base URL, модель и API-ключ.
* **Ручные роли Primary и Failover.** Просмотр провайдеров больше не меняет активного. Основной и резервный провайдеры назначаются явно; Failover автоматически подхватывает запросы при сетевых ошибках, таймаутах, 401/403/404/429 и 5xx.
* **Повторное распознавание и просмотр этапов.** Заметку можно распознать заново и сравнить сырой ASR, текст после IT-словаря и финальный результат ИИ.
* **Живое переключение языка.** Русский и английский интерфейсы переключаются на лету, включая даты, относительное время и названия ИИ-действий.

## Архитектура и возможности

* **Полная локальность расшифровки (Zero Cloud).** Распознавание речи работает локально. Аудиопоток не покидает ваш Mac. ИИ-обработка опциональна и использует только выбранного вами провайдера.
* **Direct Input.** Нажимаете `⌥ + Space`, диктуете — текст мгновенно вставляется под курсор в любом приложении: VS Code, Notion, Telegram, Xcode, Obsidian, Slack и других.
* **Аппаратное ускорение.** Модель оптимизирована под Apple Silicon (M-series) и работает через CoreML / Apple Neural Engine без перегрева CPU.
* **Понимание контекста и сленга.** Хорошо понимает русский язык, английский, IT-сленг, code-switching («рунглиш») и автоматически расставляет пунктуацию.
* **Пакетная обработка.** Офлайн-расшифровка аудио и видео любой длительности: MP3, WAV, M4A, MP4, WebM.
* **Тайминги по словам.** Караоке-подсветка при воспроизведении; тайминги синхронизируются после повторного распознавания и замен по словарю.
* **Менеджер промптов.** Редактирование встроенных ИИ-промптов, создание своих и откат изменений.
* **История и аналитика.** ИИ-трансформации сохраняются в истории с бейджами «до/после»; дашборд показывает сэкономленное время, скорость диктовки, активность и распределение заметок по размеру.
* **Двуязычность по умолчанию.** Каждая строка интерфейса доступна на русском и английском.
* **Безопасные ключи.** API-ключи хранятся в macOS Keychain, изолированно по провайдерам, с единым кэшированным доступом.

## Установка

1. Скачайте актуальный `Golosok.dmg` из раздела [Releases](../../releases).
2. Перенесите `Golosok.app` в папку `/Applications`.

**Снятие карантина macOS (Gatekeeper):**  
Проект поставляется как Open Source без платной подписи Apple Developer. Чтобы система не блокировала запуск, снимите атрибут карантина через Терминал:

```bash
xattr -cr /Applications/Golosok.app
```

*(Альтернатива в GUI: Control + правый клик по иконке → Открыть → Подтвердить).*

## Настройка доступов

При первом старте система запросит два разрешения:
1. **Микрофон** — для захвата голоса.
2. **Универсальный доступ (Accessibility)** — для автоматической вставки текста через `Cmd + V` под курсор и для горячей клавиши обработки выделения.

*(Если обновляетесь со старой версии и тумблер Универсального доступа завис — удалите приложение из списка через кнопку `-` и добавьте заново).*

## Управление

Приложение работает в фоне. Управление завязано на горячие клавиши:

* **`⌥ + Space` (Option + Пробел) — старт / стоп диктовки**
  * **1-е нажатие:** активация записи (белый островок, зелёный эквалайзер).
  * **2-е нажатие:** стоп записи, инференс (~0.1 сек) и мгновенная вставка в активное окно.
* **Push-to-Talk / режим удержания** *(выбирается в настройках)*
  * Удерживайте `⌥ + Space` для записи, отпустите — текст распознается и вставится сразу.
* **`⌥ + ⇧ + Space` — ИИ-обработка выделенного текста**
  * Открывает палитру промптов для текущего выделения в любом приложении.
* **`ESC` — отмена**
  * Жёсткий сброс текущей диктовки без сохранения и вставки.

В меню-баре (иконка вейвформы) доступны история последних диктовок, копирование результатов в буфер обмена и настройки приложения.

## ИИ-провайдеры

В приложении есть пресеты OpenAI, DeepSeek, Groq, Neuraldeep и локальных серверов (Ollama / LM Studio), а также произвольные OpenAI-совместимые endpoint'ы. Настройки провайдеров хранятся независимо: переключение просмотра никогда не перезаписывает модель или ключ другого провайдера.

Роли Primary и Failover назначаются явно:

* Откройте провайдера, чтобы посмотреть или изменить его настройки.
* Тумблер **Primary** делает его основным.
* Тумблер **Failover** делает его автоматическим резервным.

Достаточно собственного API-ключа или локальной модели — регистрация не нужна.

## Сборка из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Realmagnum/Golosok.git
cd Golosok

# 2. Скачать веса модели GigaAM
curl -L -o Golosok/gigaam.gguf https://huggingface.co/memoravox/gigaam-v3-e2e-rnnt-gguf/resolve/main/gigaam-v3-e2e-rnnt-Q8_0.gguf

# 3. Открыть проект в Xcode
open Golosok.xcodeproj
```

В Xcode нажмите `⌘ + R` для сборки и запуска.

### Скриптовые сборки (полный Xcode не нужен)

Достаточно Command Line Tools: оба скрипта компилируют через `swiftc`, копируют
ресурсы в бандл реальными файлами, генерируют локализации из String Catalog и
собирают `Info.plist` с правильной версией.

Ресурсы не хранятся в git. Укажите `GOLOSOK_RESOURCES_DIR` на каталог с `ffmpeg`,
`whisper-cli`, `transcribe-cli`, `gigaam.gguf`, `AppIcon.icns` и `Assets.car`
(по умолчанию они читаются из установленного `/Applications/Golosok.app`).

```bash
# Dev-бандл: universal, ad-hoc подпись, ../Golosok-Build/Golosok-Dev.app
./build-dev.sh
./build-dev.sh --arch arm64            # быстрее, одна архитектура

# Релиз: universal .app + DMG, подпись Developer ID, опциональная нотаризация
GOLOSOK_RESOURCES_DIR=/Applications/Golosok.app/Contents/Resources \
  ./build-release.sh --identity "Developer ID Application: Name (TEAMID)" \
                     --notary-profile golosok
```

Версия берётся из файла `VERSION`; `scripts/verify_project_invariants.py` валит сборку,
если `VERSION`, `MARKETING_VERSION` и `Info.plist` расходятся.

Тесты и релизный чек-лист:

```bash
./scripts/run-tests.sh     # smoke-набор локально, полный test-таргет при наличии Xcode
cat docs/RELEASE.md
```

Сторонние компоненты в бандле (FFmpeg, whisper.cpp, transcribe.cpp, веса GigaAM) и их
лицензии перечислены в `THIRD-PARTY-NOTICES.md`; каждая сборка кладёт файл внутрь бандла.

Если DMG подписан ad-hoc (нет сертификата Developer ID), macOS заблокирует первый запуск:

```bash
xattr -cr /Applications/Golosok.app
```
